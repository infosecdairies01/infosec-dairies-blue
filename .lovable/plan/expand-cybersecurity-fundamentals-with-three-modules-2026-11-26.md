# Expand Cybersecurity Fundamentals with Three Modules

## What will change
- Add modules 7–9 to Cybersecurity Fundamentals, drawing on the practical investigation style of [CyberDefenders](https://cyberdefenders.org/blue-team-labs/) and the junior analyst topic areas described by [Security Blue Team](https://wp.securityblue.team/).
- Use original, beginner-level content focused on phishing and email analysis, digital forensics and evidence handling, and SIEM-led blue-team investigation with threat-intelligence context.
- Add three lessons and one scenario-based quiz per module, with practical exercises where appropriate. Wire each quiz into both module access and the course quiz list.
- Update the final-exam description and course duration to reflect all nine modules; retain the existing 30-question, 80%, 60-minute exam standard.

## Implementation
- Keep new lesson and quiz content in the existing focused `cybersecurityFundamentals.ts` data module and rely on the established lesson/quiz aggregators.
- Validate lesson IDs, quiz mappings, question counts, and final-exam coverage; run the project’s available checks.
