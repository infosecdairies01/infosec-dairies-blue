# Add Cybersecurity Fundamentals

## Scope
Add a beginner-friendly, self-paced course named **Cybersecurity Fundamentals** to the existing Certifications experience. Keep the current course page, pricing, lessons, and assessment flows unchanged for other courses.

## Approach
- Add the course metadata, six modules, lesson titles, module quizzes, and a certification exam using existing course conventions.
- Write original lesson material and scenario-based assessments, with hands-on exercises for practical application.
- Connect course-specific lessons and quizzes through the existing lookup functions, and reuse the existing cybersecurity course artwork.
- Verify course lookup, lesson/quiz ID coverage, and the project build.

## Assumptions
- Treat this as a beginner/easy self-paced offering and follow the existing easy-course price and certification exam standard.
- Structure it around core security principles, threats, identity and access, endpoint/network protection, data/cloud security, and incident readiness.
